## 🛠️ Getting Started

To run any of the project tools locally, clone this repository and navigate into the respective project folder:

```bash
# Clone the repository
git clone https://github.com/kaustubhbangar5-dotcom/Prodigy_CS_Projects.git

# --- Task 01: Caesar Cipher ---
cd Prodigy_CS_01
python caesar_cipher.py

# --- Task 02: Image Encryptor ---
cd ../Prodigy_CS_02
pip install -r requirements.txt
python image_encryptor.py
```
